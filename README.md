# 🧩 Logic Box

## 📌 Project Overview

**Logic Box** is a Python-based console application that combines two useful programs in a simple **menu-driven interface**:

- ⭐ **Pattern Generator** – creates a right-angled star pattern using nested loops.
- 🔢 **Number Analyzer** – checks numbers in a given range as Odd or Even and calculates their total sum.

The project is designed to demonstrate important Python programming fundamentals such as **variables, user input, conditional statements, loops, nested loops, `range()`, `break`, `continue`, and `pass`**.

---

## 🎯 Objectives

- Build a simple menu-driven Python application
- Generate a right-angled triangle pattern
- Analyze a range of numbers
- Identify Odd and Even numbers
- Calculate the sum of numbers in a range
- Practice `for` and `while` loops
- Understand nested loops
- Use control statements such as `break`, `continue`, and `pass`
- Perform basic input validation

---

## 🛠️ Features

### ⭐ Pattern Generator
- Takes the number of rows from the user
- Generates a right-angled triangle using `*`
- Uses nested `for` loops

Example:

```text
*
**
***
****
*****
```

### 🔢 Number Analyzer
- Takes a starting number and ending number
- Uses `range()` to process the numbers
- Checks whether each number is **Odd** or **Even**
- Calculates the sum of all numbers in the selected range

Example:

```text
Number 10 is Even
Number 11 is Odd
Number 12 is Even
Number 13 is Odd
Number 14 is Even
Number 15 is Odd

Sum of all numbers from 10 to 15 is: 75
```

### 🚪 Exit
- Option 3 exits the application
- Displays a goodbye message

| Concept | Purpose |

| Nested loops | Creates the star pattern |
| range() | Generates a sequence of numbers |
| % operator | Checks Odd/Even numbers |

## ▶️ How to Run

### 1. Install Python

Make sure **Python 3.x** is installed on your computer.

### 2. Open the Project

Open the `Logic-Box` folder in VS Code or any Python IDE.

### 3. Run the Program

Open the terminal and execute:

```bash
python logic_box.py
```

### 4. Select an Option

```text
Select an option:
1. Generate a Pattern
2. Analyze a Range of Numbers
3. Exit
```

Enter `1`, `2`, or `3` according to the required operation.
